# 🌱 Planto

**A simple iOS app that helps you remember to water your plants. Add a reminder for each plant, get a notification when it is time, and check plants off as you water them.**

## ✨ Features

- 🪴 Add a reminder for each plant.
- 🔔 Get notifications when it's time to water your plants.
- 💧 Track your daily watering tasks.
- ✅ Check plants off as you water them.
- ✏️ Edit plant information.
- 🗑️ Delete plant reminders.

## 🛠️ Technologies Used


- 💻 Swift
- 🎨 SwiftUI
- 🍎 Xcode
